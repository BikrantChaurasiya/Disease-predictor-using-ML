# Disease Prediction using Machine Learning

## Project Description

This project presents a machine learning-based disease prediction
system that predicts the most likely disease based on five
user-provided symptoms.

The system processes symptom information and uses a supervised
machine learning classification approach to identify the corresponding
disease. The project demonstrates how machine learning can be applied
to healthcare-related prediction tasks.

## Objective

The main objective of this project is to develop a simple and
user-friendly disease prediction system that can analyze five symptoms
and provide a predicted disease based on patterns learned from the
training dataset.

## How It Works

User enters five symptoms
        ↓
Symptom Data Processing
        ↓
Feature Representation
        ↓
Machine Learning Model
        ↓
Disease Prediction

## Input

The system uses five symptoms as input:

- Symptom 1
- Symptom 2
- Symptom 3
- Symptom 4
- Symptom 5

## Output

The trained machine learning model predicts the corresponding disease
based on the provided symptoms.
